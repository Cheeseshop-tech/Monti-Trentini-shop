The keystone: an adapter layer

Don't fuse the two. Map both onto one normalized product schema, and let each surface read what it needs from it.

One schema in the middle means each side keeps its own currency, units & audience — no lossy merge.

Build sequence

Order chosen to de-risk: prove the data bridge, then layer features cheapest-first.

Map ~70 USD SKUs to storefront products; decide which features are consumer vs trade-only.

Image catalogFeature A

InventoryFeature B

CalculatorFeature C
